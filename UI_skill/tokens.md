## Figma 变量集合

当前 `01_Components` 已建立变量集合：

`感受地图 / 01 设计 Token`

模式：

- `数值`

用途：

- 记录当前组件页中已确认的颜色、透明度、尺寸、描边、圆角和字体信息
- 供后续正式页面或代码实现对齐
- 不把无法语义区分的内部 Vector 编号当作 token

- `颜色/图标/状态栏` 只用于状态栏文字和 Material Icons

- `Overlay / 底部功能遮罩（伸缩前）`

## 切换遮罩

来源：Figma `01_Components` → `Overlay / 切换遮罩`。

用途：

- 用于视图切换时从侧向 / 大范围压暗背景
- 不与 `Overlay / 底部功能遮罩` 混用；底部功能遮罩负责承托底部导航，切换遮罩负责过渡时的整体遮蔽
- 当前 prototype 为两态 Smart Animate：`Transition Mask / 00 白光进入` → `Transition Mask / 01 暗遮罩落点`
- 触发：`On Click`
- 曲线：Custom cubic bezier `(0, 0, 0, 1)`
- 时长：`0.8s`

## 代码映射

Figma 变量名和 WEB code syntax 都先使用中文。WEB code syntax 由变量名的 `/` 转成 `-`：

```text
颜色/图标/主要       var(--颜色-图标-主要)
透明度/时间轴        var(--透明度-时间轴)
尺寸/时间轴/滑块     var(--尺寸-时间轴-滑块)
```

说明：

- 当前阶段以设计理解为优先，token 先全部中文化
- 进入代码实现前，再决定是否建立英文 alias 或导出映射表

## 不作为 Token 的内容

- `WorldClosed01`、`SenseOpen03`、`AvatarMarker02` 等内部图层编号
- 组件展示页中的摆放坐标
- 单个 Vector path 的几何尺寸
- 临时测试 Frame 或过渡备注

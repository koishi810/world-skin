# 命名规范

## 基本原则

- 名称优先表达语义，而不是表达“它长得像什么”。
- 命名应帮助之后的人快速判断：
  - 这是哪一层
  - 它属于哪个区域
  - 它在界面里承担什么功能

## 推荐命名

- `Header / 头部`
- `Header / 返回按钮`
- `Content / 设置主体`
- `Section / 表示`
- `Section / 记录`
- `Section / 通知`

## 尽量避免

- `Group 1`
- `Rectangle 2`
- `Layer 5`

临时阶段可以先用，但一旦页面方向确定，就应该及时清理。

## 命名风格

- 优先使用：
  - `英文类别 / 中文语义`
- 例如：
  - `Header / 返回按钮`
  - `Section / 最近记录`
  - `Actions / 底部操作`

## 额外约定

- 顶部如果承担返回功能，不要因为它看起来像标题就命名成普通标题。
- 如果它是返回入口，应按：
  - `Header / 返回按钮`
  来整理。

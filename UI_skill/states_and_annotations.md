# 页面状态与备注

同一页面多状态、过渡帧、滚动页面的表达方式。

---

## 同一页面多状态

- 尽量用同一套图层结构
- 不同状态只改内容，不另起图层组织方式
- 命名示例：
  ```
  Settings / FULL
  Settings / Viewport Top
  Settings / Viewport Bottom
  ```

---

## 正式状态 vs 过渡帧

**正式状态**：产品里真实存在的稳定页面，实装时作为主要参考。

**过渡帧**：只服务 Figma 原型补间或说明动效路径，不要求逐帧照搬实现。

区分方法：
- 是 Figma 里的补充帧 → 在 Frame 底部外侧备注 `测试用途：...`
- 是可独立交互的落点 → 正式状态，在 `screen_patterns.md` 中记录

---

## 上下帧备注

不把 From/To 写进图层名，太长。统一在 Frame 底部外侧加：
```
From: 00 Viewport Top
To: 02 Viewport Bottom
```

样式：10–12px，白色 35–45%，左对齐跟 Frame 左边缘，距底部 8–16px。

---

## 长页面表达

同时保留：
- 完整长图：看结构
- 顶部 viewport：看进入状态
- 底部 viewport：看滚动到底部状态

---

## 底部功能遮罩上浮状态（复用规则）

来源：Figma `01_Components` → `Overlay / 底部功能遮罩`。

这组状态用于所有同类底部功能遮罩动效。核心不是让每一帧都可见，而是记录从低可见度起点到暗遮罩落点的运动路径。

| State | 类型 | 说明 |
|---|---|---|
| State 00 / 伸缩前 | 过渡起点 | 白色到暗色的低可见度遮罩，`x=39 y=1102`，opacity `10`，作为上浮起点 |
| State 01 / 上浮进入 | 动画补间 | 遮罩从底部外侧进入，可出现短暂白光 / 白雾，不作为稳定页面 |
| State 02 / 沉入暗遮罩 | 动画补间 | 白光降低，暗遮罩增强，底部导航逐渐被托住 |
| State 03 / 伸缩后暗遮罩 | 稳定落点 | 暗色底部遮罩位于 `x=581 y=863`，opacity `90`，使用 5 段暗色渐变 |

实装原则：

- State 00 是伸缩前状态，低可见度是正确状态，不要当成缺失或跑位修正
- 同类动效复用 `UI_skill/tokens.md` 中的「底部功能遮罩动效」token
- 白光只用于进入动效，最终状态不保留明显白边
- 如果 Figma 只有 State 00 和 State 03，中间帧由代码插值生成，不必补画

## 切换遮罩状态（复用规则）

来源：Figma `01_Components` → `Overlay / 切换遮罩`。

这组状态用于页面 / 视图切换时的大范围遮蔽，不承托底部导航，也不替代 Sense 专属上下遮罩。

| State | 类型 | 说明 |
|---|---|---|
| `Transition Mask / 00 白光进入` | 过渡起点 | `#0B0D0F / 86%` 到 `#D9D9D9 / 100%` 的 2 段渐变，用于亮面扫入 |
| `Transition Mask / 01 暗遮罩落点` | 稳定落点 | 5 段暗色渐变，作为文本页面和视图切换后的稳定遮罩 |

Prototype：

- 触发：`On Click`
- 转场：`Smart Animate`
- 曲线：Custom cubic bezier `(0, 0, 0, 1)`
- 时长：`0.8s`

实装原则：

- 文本页面稳定态统一使用 `Transition Mask / 01 暗遮罩落点`
- 不额外叠 `Overlay / 页面遮罩`
- 白光状态只服务过渡，不作为常驻背景
- 同类视图切换复用 `UI_skill/tokens.md` 中「切换遮罩」参数

## Sense 遮罩补充

Figma `01_Components` 已新增 `Overlay / 其他遮罩`，版式与其他遮罩 section 保持一致：示例画面 + 独立遮罩图层，不使用 panel/card。

当前已补入真实组件预览：

- `Overlay / 其他遮罩 / 上滑进入`
  - 来源：`Sense / 记录动画` → `Sense Flow / 02 接触层显影` → `Feature / 01 底图` → `上滑遮罩`
  - 遮罩图层保持 section-level 节点，坐标对齐 `示例画面1 / 上滑遮罩`
- `Overlay / 其他遮罩 / 下拉退出`
  - 来源：`Sense / 记录动画` → `Sense Flow / 11 记录完成` → `Overlay / 下拉遮罩`
  - 遮罩图层保持 section-level 节点，坐标对齐 `示例画面2 / 下拉遮罩`

处理原则：

- 这两类先不要混入 `Overlay / 切换遮罩`
- 只有确认会跨页面复用时，才建立正式 token 和稳定组件
- 如果只服务 Sense 单一流程，可以继续留在 `Sense / 记录动画` 内，不必升成全局遮罩

### test0.3 实装规则（2026-05-19 验证）

- 以上 Sense frame 不做成 11 个独立 view，统一挂在 `#view-sense`
- 正式状态对应 `data-sense-stage` 的稳定落点：`ready` / `selecting` / `complete`
- 02、03、05、06、07、10 等中间帧只作为动画关键状态和透明/缩放过渡参考
- `603:917` 是词团变化前的透明/缩小过渡参考，不单独建立状态
- Figma 拆分素材优先从 `test0.3/assets/figma/sense-sXX-*` 读取；缺失时再回查 `素材0.3/Feature States/三个功能.svg`
- Sense 视觉完全使用 Figma 拆分素材层：mapcore / effect / core；不再保留旧 CSS 雾层、呼吸 ring 或额外 `sense-core`
- Sense 的旧文本状态节点不可保留；选择阶段只渲染 Figma 词团素材，按钮文字不得可视化
- Sense 背景使用独立灰雾遮罩，底图可见但必须低对比、不可操作
- 1:1 复刻 Sense prototype 时，不能用实时地图替代 Figma 的 `Background / 背景层`；必须使用本地化的 Figma 背景图与原始遮罩坐标
- Sense 文案必须按 Figma 原文和坐标保留：待机态 `押しつづける / 10秒のあいだ`，第一轮 `いまの感覚に近い言葉を選ぶ` + `浮く / 詰まる / 流れる`，第二轮 `もう少しだけ近いものを選ぶ` + `重い / 乾く / ほどける`
- 采样呼吸动效按气球节奏实现：4s 缓慢膨胀、2s 轻微呼吸浮动、4s 缓慢收缩消失；总时长 10s，曲线必须非线性且不能突然变大
- 词选圆团以 Figma 08 / 09 为基准区域，但实装时每轮随机词、随机位置微偏移和随机尺寸；中心保留感知核心的小圆残影
- 词选底部主文案固定为 Figma 坐标 `x=112 y=750 w=182 h=17`；不得继承居中用的 `translateX(-50%)`

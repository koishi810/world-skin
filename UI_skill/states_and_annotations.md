# 页面状态与备注

同一页面多状态、过渡帧、滚动页面的表达方式。

---

## 同一页面多状态

- 尽量用同一套图层结构
- 不同状态只改内容，不另起图层组织方式
- 命名示例：
  ```
  Settings / FULL
  Settings / Viewport Top
  Settings / Viewport Bottom
  ```

---

## 正式状态 vs 过渡帧

**正式状态**：产品里真实存在的稳定页面，实装时作为主要参考。

**过渡帧**：只服务 Figma 原型补间或说明动效路径，不要求逐帧照搬实现。

区分方法：
- 是 Figma 里的补充帧 → 在 Frame 底部外侧备注 `测试用途：...`
- 是可独立交互的落点 → 正式状态，在 `screen_patterns.md` 中记录

---

## 上下帧备注

不把 From/To 写进图层名，太长。统一在 Frame 底部外侧加：
```
From: 00 Viewport Top
To: 02 Viewport Bottom
```

样式：10–12px，白色 35–45%，左对齐跟 Frame 左边缘，距底部 8–16px。

---

## 长页面表达

同时保留：
- 完整长图：看结构
- 顶部 viewport：看进入状态
- 底部 viewport：看滚动到底部状态

### test0.3 实装规则（2026-05-19 验证）

- 以上 Sense frame 不做成 11 个独立 view，统一挂在 `#view-sense`
- 正式状态对应 `data-sense-stage` 的稳定落点：`ready` / `selecting` / `complete`
- 02、03、05、06、07、10 等中间帧只作为动画关键状态和透明/缩放过渡参考
- `603:917` 是词团变化前的透明/缩小过渡参考，不单独建立状态
- Figma 拆分素材优先从 `test0.3/assets/figma/sense-sXX-*` 读取；缺失时再回查 `素材0.3/Feature States/三个功能.svg`
- Sense 视觉完全使用 Figma 拆分素材层：mapcore / effect / core；不再保留旧 CSS 雾层、呼吸 ring 或额外 `sense-core`
- Sense 的旧文本状态节点不可保留；选择阶段只渲染 Figma 词团素材，按钮文字不得可视化
- Sense 背景使用独立灰雾遮罩，底图可见但必须低对比、不可操作
- 1:1 复刻 Sense prototype 时，不能用实时地图替代 Figma 的 `Background / 背景层`；必须使用本地化的 Figma 背景图与原始遮罩坐标
- Sense 文案必须按 Figma 原文和坐标保留：待机态 `押しつづける / 10秒のあいだ`，第一轮 `いまの感覚に近い言葉を選ぶ` + `浮く / 詰まる / 流れる`，第二轮 `もう少しだけ近いものを選ぶ` + `重い / 乾く / ほどける`
- 采样呼吸动效按气球节奏实现：4s 缓慢膨胀、2s 轻微呼吸浮动、4s 缓慢收缩消失；总时长 10s，曲线必须非线性且不能突然变大
- 词选圆团以 Figma 08 / 09 为基准区域，但实装时每轮随机词、随机位置微偏移和随机尺寸；中心保留感知核心的小圆残影
- 词选底部主文案固定为 Figma 坐标 `x=112 y=750 w=182 h=17`；不得继承居中用的 `translateX(-50%)`

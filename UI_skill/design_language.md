# 设计语言

这个文件用于记录项目整体的视觉与交互气质。  
后续当需要“整理设计语言”“统一页面气质”“判断某个改动像不像这个项目”时，优先把结论写到这里。

## 当前已明确的方向

- 整体应保持冷静、暗色、低饱和、身体性的气质。
- 信息层级要清楚，但避免普通工具 App 那种过度功能化的强对比。
- 文本页、个人页、记录页之间可以有不同密度，但不应跳出同一套视觉世界。
- 图标应服务识别，不应抢走页面主导权。
- 页面应保留呼吸感，不要为了“填满”而把所有信息都塞进首屏。

## 文案与内容倾向

- 用户可见文案优先使用日文。
- 说明文字应简洁，不直接暴露算法、参数、内部结构。
- 文案要更接近感受与行为，而不是后台术语。

## Contact / 接触层

当用户进入现场采样时，画面应优先表现为 `Contact / 接触层`，而不是普通弹窗或 CTA。

当前已确认：

- 长按约 `10 秒` 是身体性记录本身，不只是进入记录前的确认动作。
- 采样状态应像手机正在贴近地表读取纹理，而不是在地图上方叠一个按钮。
- 画面可以出现收缩、扩散、雾状覆盖、压痕和轻微不稳定，但应保持连续、缓慢、低干扰。
- 采样完成前只显示临时接触状态，不提前生成正式记录痕迹。
- 默认不使用边缘清晰的主按钮；可按区域应从环境状态中显影出来。

### 画面倾向

- 雾状扩散可以作为接触层的进入方式，但它必须服务于“读取城市皮肤”，不能只像装饰性柔光。
- 中央长按区可以逐渐凝结，但边缘应尽量柔软，避免传统按钮轮廓。
- 进度感优先通过密度、压痕、扩散和环境变化表达；倒计时或进度环不是默认方案。
- 如果使用说明文字，文案应轻、短、状态化，不要盖过画面本身。

## 文字型信息页的层级节奏

以下规则目前适用于**以文字信息为主、由多个 section 构成的页面**，例如记录页、个人资料详情页这类界面。  
它不是所有页面的通用模板；地图主界面、强图像主导页面或特殊动效页面可以有不同节奏。

当前可复用的版面关系：

- 上一区块结束或分割线 → 下一 section 标题：约 `20px`
- section 标题 → 第一层主要内容：约 `20px`
- section 主要内容结束 → 下一条分割线：约 `26px`
- 页面头部可单独处理，不必机械套用普通 section 的距离关系

这套规则的目标是让页面保持：

- 清楚的阅读顺序
- 安静、稳定的垂直节奏
- 同类信息页之间的一致性

### 适用边界

- 这是一套**文字层级与间距关系**，不是完整视觉规范。
- 当前只确认了结构与节奏，**配色方案尚未最终确定**。
- 后续若调整文字颜色、分割线明度、透明度层级，应在配色方案确定后统一补充，而不是现在提前写死。
